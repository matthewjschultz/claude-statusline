# Security Policy

## Supported versions

Only the current `main` branch is supported; there are no maintained older versions.

## Reporting a vulnerability

If you find a security vulnerability in this status line tool (e.g. in how it handles
credentials, API responses, or local config), please report it privately using GitHub's
**Report a vulnerability** button on this repo's
[Security tab](https://github.com/matthewjschultz/claude-statusline/security/advisories/new).

Please do not open a public issue for security reports.
